# Sunshine Studios — App Portfolio & Web Properties

Official portfolio and hub for Sunshine Studios native Apple applications (iOS, watchOS, macOS).

## 🚀 Live Web Properties

1. **[Focus Timer - GrowFocus](https://themansigoel.github.io/grow-focus-web/)** — Gamified 3D botanical sanctuary and cognitive focus timer with 10 attention gym games, Pomodoro anti-wilt stakes, and Apple HealthKit integration.
2. **[Mantra Chanting: Japa Mala](https://themansigoel.github.io/mantra-chanting-web/)** — Native iOS & watchOS prayer bead simulator with tactile haptics and hands-free voice chanting.
3. **[Break Reminder: Step Away](https://themansigoel.github.io/stepaway/)** — Meeting-aware macOS break timer with Spine Align and 20-20-20 Blink Guide HUDs.
4. **[Go Phonics: Kids Learn to Read](https://themansigoel.github.io/go-phonics/)** — Interactive phonics learning app with 6 progressive levels for early readers.
5. **[Kiddo Puzzle: Learning Game](https://themansigoel.github.io/kiddo-puzzle/)** — COPPA-safe tactile shape puzzles with 70+ animals and fruits.

## 🛠️ Technology & Design Principles
- **Native Apple Frameworks**: Swift, SwiftUI, SpriteKit, Metal, HealthKit, StoreKit 2.
- **Privacy by Design**: 100% on-device data persistence via SwiftData and private iCloud containers. Zero telemetry servers, zero user tracking.
- **Liquid Glass & Bento Design**: Apple Design Award inspired glassmorphic surfaces, fluid micro-interactions, and accessible typography.
